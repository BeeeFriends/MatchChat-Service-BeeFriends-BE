# BeeFriends Match & Chat Service

Template service for BeeFriends matching and chat flows.

## Development

```bash
npm install
npm run start:dev
```

Default endpoints:

- `GET /api/v1/health`
- `GET /api/v1/match-chat`
- Swagger: `/docs`

## Notes

This is a starter template only. Add database, queues, websocket gateway, or external integrations when the service contract is finalized.
